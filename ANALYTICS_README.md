# Система сбора аналитических данных

Эта система собирает подробную информацию о пользователях и их устройствах для BigData аналитики.

## Что собирается

### Информация о браузере
- User Agent
- Название браузера (Chrome, Firefox, Safari, Edge и т.д.)
- Версия браузера
- Движок браузера (Blink, Gecko, WebKit)

### Информация об операционной системе
- Название ОС (Windows, macOS, Linux, Android, iOS)
- Версия ОС
- Платформа

### Информация об устройстве
- Тип устройства (desktop, mobile, tablet)
- Производитель устройства
- Модель устройства

### Информация об экране
- Разрешение экрана (ширина, высота)
- Глубина цвета
- Pixel ratio
- Размер viewport

### Локализация
- Язык браузера
- Список поддерживаемых языков
- Часовой пояс
- Смещение часового пояса

### Сетевая информация
- Тип соединения
- Эффективный тип соединения

### Дополнительная информация
- Поддержка cookies
- Онлайн статус
- Referrer (откуда пришел пользователь)
- Текущий URL
- Временная метка

### Идентификаторы
- **Visitor ID** - уникальный идентификатор посетителя (хранится в localStorage)
- **Session ID** - идентификатор сессии (обновляется каждые 30 минут)

### Производительность
- Количество ядер процессора
- Объем памяти устройства
- Максимальное количество точек касания

## Использование

### Автоматический сбор данных

Данные собираются автоматически при загрузке приложения через `useAnalytics()` composable в `App.vue`.

### Ручной сбор данных

```typescript
import { collectUserDeviceInfo } from './services/analytics'
import { sendAnalyticsData } from './services/api'

const data = collectUserDeviceInfo()
await sendAnalyticsData(data)
```

### Отслеживание событий

```typescript
import { useAnalytics } from './composables/useAnalytics'

const { trackEvent } = useAnalytics()

// Отслеживание клика
trackEvent('button_click', { buttonId: 'submit' })

// Отслеживание перехода
trackEvent('page_view', { page: '/contacts' })
```

## Настройка сервера

1. Скопируйте `server-example.js` и адаптируйте под ваш стек
2. Установите зависимости: `npm install express cors body-parser`
3. Запустите сервер: `node server-example.js`
4. Настройте URL в `.env` файле:

```env
VITE_API_URL=http://localhost:3000/api
```


## Безопасность и приватность

⚠️ **Важно**: При использовании этой системы убедитесь, что вы:

1. Соблюдаете GDPR и другие законы о защите данных
2. Получаете согласие пользователей на сбор данных
3. Храните данные безопасно
4. Не собираете персональные данные без согласия
5. Предоставляете возможность пользователям отказаться от сбора данных

## Рекомендации для продакшена

1. **База данных**: Используйте MongoDB, PostgreSQL или другую БД вместо массива в памяти
2. **Очередь сообщений**: Используйте Redis/RabbitMQ для обработки больших объемов данных
3. **Аналитика**: Интегрируйте с системами аналитики (Google Analytics, Mixpanel, Amplitude)
4. **Мониторинг**: Настройте мониторинг и алерты
5. **Rate Limiting**: Добавьте ограничение частоты запросов
6. **Валидация**: Усильте валидацию входящих данных
7. **Шифрование**: Используйте HTTPS для передачи данных

## Примеры использования данных

Собранные данные можно использовать для:
- Анализа аудитории (какие устройства, браузеры, ОС используют)
- Оптимизации под конкретные устройства
- A/B тестирования
- Сегментации пользователей
- Анализа поведения пользователей
- Оптимизации производительности
